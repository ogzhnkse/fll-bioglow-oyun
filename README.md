# FLL BIOGLOW 3D

FIRST LEGO League Challenge **BIOGLOW (2026-27)** sahasinin tarayicida oynanan 3D modeli: masa, mat ve
15 gorevin modelleri, hareketli parcalariyla.

**Oyna:** https://ogzhnkse.github.io/fll-bioglow-oyun/

Bu repo yalnizca yayimlanan oyunu icerir. Gorevler, mat gorseli ve saha yerlesimi FIRST'un yayimladigi
BIOGLOW materyallerinden alinmistir; haklari FIRST ve LEGO Group'a aittir. LEGO parca geometrisi LDraw
kutuphanesinden (CC BY 2.0). Bu proje resmi degildir; FIRST veya LEGO Group ile baglantili degildir.
